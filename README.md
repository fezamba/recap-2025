#recap-2025

Aplicação web para criar e compartilhar uma **retrospectiva personalizada de 2025**, focada em uma experiência simples, rápida e visual.  
O projeto permite ao usuário revisar momentos do ano em um fluxo guiado, com interface moderna e responsiva.

## Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**

## Objetivo do projeto

O **recap-2025** foi criado como um projeto frontend para:
Praticar Next.js solucionando um problema da minha mãe que queria um site para utilizar com as amigas.

## Execução local

```bash
git clone https://github.com/fezamba/recap-2025.git
cd recap-2025
npm install
npm run dev
```

Acesse http://localhost:3000
